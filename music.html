Import your ratings

Load a ratings export to explore your artists, albums and top songs. The file is read in your browser and isn't uploaded anywhere.

or drop a .json file anywhere on this page

What format does it expect? 
[
  { "rating": 4.5,
    "tracks": [
      { "name": "Song title",
        "uri": "spotify:track:…",
        "artists": [{ "name": "Artist" }],
        "album": { "name": "Album",
                   "artist": { "name": "Artist" },
                   "images": [] },
        "release": { "isoString": "2019-05-17" } }
    ] }
]

One entry per rating value, each with its list of tracks. A top-level { "ratings": [...] } or { "data": [...] } wrapper also works. To skip this step, put ratings-export.json in the same folder as this page and it loads automatically.
