or drop a .json file anywhere on this page

What format does it expect? 
[
  { "rating": 4.5,
    "tracks": [
      { "name": "Song title",
        "uri": "spotify:track:…",
        "artists": [{ "name": "Artist" }],
        "album": { "name": "Album",
                   "artist": { "name": "Artist" },
                   "images": [] },
        "release": { "isoString": "2019-05-17" } }
    ] }
]

One entry per rating, each with its tracks. A { "ratings": [...] } or { "data": [...] } wrapper works too. Or just drop ratings-export.json next to this page and it'll load on its own.
